# Serialize JSON - Java

Projeto desenvolvido em Java utilizando Maven e VSCode.

## Objetivo

Criar uma aplicação simples que realiza a **serialização de um objeto Java para JSON** utilizando a biblioteca **Gson**.

## Tecnologias utilizadas

- Java
- Maven
- VSCode
- Gson

## Estrutura do projeto

Classe **Pessoa**

Contém os atributos:

- name
- idade

Classe **Main**

Responsável por criar um objeto Pessoa e convertê-lo para JSON utilizando a biblioteca Gson.
